# AI Usage — StackNeverflow

This document describes how AI tools were used during the development of StackNeverflow.

## Tools Used

- **Claude Code** (Anthropic) — AI-assisted pair programming for code generation, architecture design, and implementation planning.

## How AI Was Used

- **Architecture & Planning:** AI was used to analyze the PROJECT_INIT.md requirements and produce a phased implementation plan with dependency ordering and verification steps.
- **Code Generation:** AI generated boilerplate code, entity definitions, service logic, controllers, DTOs, and frontend components.
- **Code Review:** AI reviewed generated code for correctness, security, and adherence to NestJS/Next.js best practices.
- **Documentation:** AI assisted in writing README, API documentation, and inline code comments.

## Human Oversight

All AI-generated code was reviewed and tested by the developer. Architectural decisions were discussed and confirmed before implementation. The developer made final decisions on all design trade-offs.
